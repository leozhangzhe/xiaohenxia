# C 方案正式 UI 迁移

采用用户选定的 C · Fluent 主导样板。浅蓝紫画布、白色工作面、14px 面板与 8px 控件、蓝紫品牌及盾牌扫描图标保留。没有新增大型框架、CDN、3D 或展示动画。

## 页面与既有接口

| 页面 | 入口 | 数据 |
| --- | --- | --- |
| 登录 | /login | 原 Session、MySQL、认证 CSRF 与密码校验 |
| 总览 | /#overview | livelist、liveavailability、privacyactionlist；原扫描列表保留在 /#scans |
| 新建检索 | /livesearch#new | livecreate POST；按类型选择来源 |
| 检索进度 | /livesearch#progress[/随机任务ID] | liveget、livelist、livecancel、livedelete |
| 统一结果 | /livesearch#results[/随机任务ID] | 同一已保存任务；筛选器与结果优先，任务操作与来源状态随后；按来源/类型筛选，展开证据与覆盖说明 |
| 申请与跟进 | /privacyaction | 原记录、删除、本地脱敏、管理员跟进接口 |

新建、进度与结果是同一既有 Mako 路由的三个前端视图，没有新路由或接口。片段只含视图名和随机任务 ID；不含查询值或 token。总览只汇总既有接口允许读取的最近 100 个本用户任务，不承诺无限历史或新增分页服务。

## 共享设计实现

- `static/css/fluent.css` 定义 `--fl-*` 色彩、字体、间距、圆角、状态、层次与控件令牌，以及 `fl-*` 组件。
- 旧 `pg-*` 页面由 `.fluent-body` 命名空间映射同一组令牌；原扫描/分析/监控入口保留。
- `fluent-ui.js` 只读取已授权的总览接口，使用 textContent 和 DOM 节点呈现数据。接口失败显示不可用，计数不会降为 0。
- 统一检索继续使用 `csrf.js` 的 Session token 传输。创建、取消、删除仍使用原 POST 接口，权限判断仍由服务端执行。
- 登录保留真实 POST、用户名、密码、next 与 CSRF；样板免密账号和合成数据未进入正式界面。
- 来源状态不等于风险结论；结果标题、字段、原始链接、时间、可信说明与误报/覆盖边界保留。HTTP/HTTPS 链接校验和 HTML 转义继续执行。
- 普通申请页不显示管理员处理组件；由既有 is_admin 控制。保存记录不会自动联系平台，不承诺第三方执行或处理时限。
- 申请方式使用原生按钮与 `data-action="delete|hide|mask"` 选择操作；隐藏申请不使用 Bootstrap 的 `hide` 类，避免按钮被样式隐藏。
- 所有字体采用本地系统字体；原 Google Fonts 加载移除，浏览器不再依赖该 CDN。

## 响应式与轻量反馈

1440px 使用 240px 侧栏、78px 顶部、主工作区与辅助上下文双栏；900px 及以下主辅内容纵排；680px 及以下顶部为 64px，使用横向导航，可展开访问其他功能。390px 申请表格转为字段带标签条目，结果卡保留所有字段，原生扫描宽表保留容器内横向滚动。

仅保留短控件颜色/阴影反馈与进度 transform 变化。没有装饰性页面入场、3D 或展示级动效。尊重 prefers-reduced-motion。

## 验证

运行 stage1–stage5 全阶段回归；新增真实 HTTP 资产/方法/CSRF 检查与来源筛选后的空白/故障状态回归。浏览器集中检查六页的 1440×1000 与 390×844；集中修复后一次最终确认。具体计数、截图及真实浏览器流程见本轮开发自测结果文档。
