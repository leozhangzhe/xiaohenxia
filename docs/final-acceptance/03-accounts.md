# 演示账号说明

源码及ZIP没有预设用户账号和通用演示密码，不提供admin/admin123。

| 账号 | 用途 | 创建与密码 |
| --- | --- | --- |
| admin | 人工跟进管理 | 独立演示工作区首次启动设置强密码，操作者保管 |
| demo_user_a | 创建扫描、统一检索及申请 | 在真实注册页创建；自行设置密码 |
| demo_user_b | 验证跨用户隔离 | 在真实注册页创建；使用不同的自行设置密码 |

这些名字是建议的合成用户名，不表示当前5001实例已存在它们。当前5001和桌面工作区的账号不自动合并。不要把临时验收脚本的随机密码当作可用演示密码。

密码只在可信窗口/表单输入，不写入Git、README、Shell命令参数、普通日志或录屏。独立验收自动生成的密码只在进程内使用，数据库存PBKDF2哈希；本轮不读取或公布用户已有凭据。

忘记管理员密码时，按auth-stage1.md的显式改密流程操作自己确定的数据库，确认备份和目标后才改密。不自动重置，不清库，不修改其他工作区账号。
