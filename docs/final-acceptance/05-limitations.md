# 已知限制

1. 实时来源依赖网络、平台规则、验证码、限流和许可证/API条款；部分完成、失败、超时、未配置必须保留区别。没有全网查全、绝对安全或身份归属承诺。
2. 本轮外网DNS测试出现与预期不符的地址和IPv6解析失败，疑似代理或环境DNS改写；未进一步核实系统配置，不能确认根因。不可用此网络下的解析结果证明真实公网归属。建议赛前由操作者检查自己的代理/TUN/DNS配置；本轮没有修改系统网络设置。
3. 本轮来源状态：SpiderFoot完成；Sherlock、WhatsMyName、Holehe部分完成；Maigret失败；HIBP未配置。没有重试来追求命中，没有将失败归零。具体时间及结果见测试报告。
4. 用户名站点范围有限（10/25/10），Holehe只调用GitHub/Gravatar；邮箱注册信号不是泄露证据，HIBP仅覆盖其收录事件且需要有效Key。
5. 本地SQLite只有合成样例，不是实时互联网数据。样例无匹配不能显示安全。
6. 申请是记录与人工跟进，没有自动向平台提交/自动删除渠道，不保证平台执行，不承诺1–3天完成。管理员应依据真实联系记录选择状态。
7. Windows x64、Python3.12、MySQL8.0.46为验证组合。安装不是离线免安装包，规则/依赖应提前准备；运行无需Node。
8. 日常工作区与临时5001验收工作区可能不同，账号不自动合并。DPAPI绑定本机当前Windows用户；跨机重新初始化。
9. 退出沿用既有GET导航。历史sfcli.py远程客户端仍是旧Digest模型，未完成对新Session/CSRF接口的完整适配；参赛以Web为正式入口，不能声称旧远程CLI已全部兼容。
10. 历史测试含原有TODO跳过和过时的未鉴权/GET写接口/英文界面预期。保留这些测试及失败，不将它们计为真实功能通过。完整结果见08-tests.md。
11. 旧Robot/Selenium脚本没有当前登录步骤，使用旧UI定位和默认5001；本轮不向用户正在运行的服务直接执行它。不能把其未执行说成通过；真实认证/业务验收以HTTP、数据库、DOM回归和用户先前视觉验收分别说明。
12. 无公网生产部署、集群、HTTPS/TLS运维、登录限流和灾备的完整保证；旧Bootstrap/jQuery依赖为兼容保留。复杂视觉在reduced-motion、移动端或WebGL不可用时降级，不应阻塞功能。
