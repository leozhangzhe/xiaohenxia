# 现场失败备用方案

## 外网失败 / DNS结果异常

停止重复检索，展示来源实际失败/部分完成/超时，说明当前网络和覆盖限制。切换本地合成样例、真实用户隔离、申请记录与管理员人工备注演示。提前采集的录屏/截图只能标注日期、网络和“预录/历史”，不能冒充现场查询。不能将失败说成无风险。

本轮DNS地址与测试预期不符，疑似环境改写，但未核实根因；比赛前由操作者检查代理/TUN/DNS。若无权调整现场网络，保留不可用状态演示，不自动改机器网络配置，不伪造DNS或平台结果。

## HIBP无Key / 工具未安装

展示未配置/未安装及重建说明。无Key不发请求，不借用他人Key，不在演示时把Key贴到页面或日志。缺工具不改成已完成。

## 数据库不可用

展示明确错误/维护状态；查看工作区web.log、mysql/server.log，确认自己启动的实例。不要临时回退内存账号、清库或默认弱密码。若来不及修复，使用提前验证的独立备用目录和合成账号，明确这是另一演示工作区；不要复制原用户数据库。

## 5001端口占用 / 启动窗口丢失

先判断是否已有正确实例；能访问就使用已有实例。需要关闭时只在所属启动窗口Ctrl+C，或先以端口确认PID、核对本项目命令行后处理。禁止按python.exe/mysqld.exe名称批量结束。不要删除PID/数据库文件来碰运气。

## 页面资源丢失 / 电脑无Node

从干净提交包恢复正式auth.js/auth.css和第三方发布资源，通过安装脚本恢复兼容路径。不要现场运行全项目npm重构。包内构建已可运行，无Node不是失败原因。

## 动效卡顿 / 投影兼容问题

启用系统减少动态效果或使用WebGL静态降级，继续展示可读表单、表格和状态。不要为了录屏开启虚假进度或完成动画。

## 忘记密码

切换自己提前创建的普通演示账号或按显式管理员改密流程处理指定演示库。不要使用admin123，不清除已有账号，不曝光DPAPI或数据库密码。

备用材料只展示合成数据；离线备用运行环境需赛前完成依赖、规则、账号创建与正常重启验证。仅有ZIP不等于有可立即运行的离线环境。
